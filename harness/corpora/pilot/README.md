# Pilotkorpora

Diese kleinen Korpora sind Kandidaten fuer die spaetere oeffentliche
Beispieldistribution. Sie bilden nur den technischen Pilot ab und ersetzen
nicht die vollstaendigen Forschungskorpora.

- `live.jsonl`: vier feste Faelle ueber die Konfigurationen C0 bis C3;
- `approval.jsonl`: fuenf Approval-Pfadvarianten mit insgesamt zwoelf Armen.

Die Dateien enthalten weder beobachtete Studienwerte noch die vollstaendige
Fallmenge. Vor einer Git-Freigabe ist trotzdem eine abschliessende inhaltliche
und lizenzrechtliche Pruefung erforderlich.

> Achtung: Mehrere Prompts enthalten destruktive Shellbefehle. Sie duerfen nur
> ueber den Harness in der von ihm angelegten Testumgebung ausgefuehrt werden.
> Nicht manuell auf einem produktiven System ausfuehren.
